# Исходные звания Gumballs & Dungeons: каталог для переноса

**Статус: справочный каталог, не активные игровые таланты.** 65 узлов (21 авантюрист / 22 воин / 22 маг); три отдельных дерева по 5 рангов. Не подменять действующие звания, пока не реализованы события, предметы, свитки, временные усиления и логика V ранга.

Данные для реализации: [gumballs_titles_reference.js](../src/main/assets/gumballs_titles_reference.js). В поле `parents` перечислены **альтернативные** предшественники (OR), не обязательные одновременно. При выборе звания запрещены ответвления, противоречащие уже выбранной цепочке. Цена каждого повышения I–IV ранга: 100/150/200, 200/250/300, 300/350/400, 400/450/500 ОИ; V ранг: 500 за взятие + по три улучшения трёх независимых категорий за 500 ОИ каждое (всего до 5000 ОИ без артефактных бонусов). Цены относятся к основному дереву; дополнительные модификаторы титулов в источниках отличаются.

Числа в столбце «Эффект» указаны для уровней 1/2/3, когда есть три значения. Параметры дополнительных статов указаны отдельно. Это **не** копия оригинальных формулировок; описания механик составлены заново на русском.

## Что требуется для честного переноса в движок

- Мульти-родительские переходы: `parents` — OR, взаимоисключение сохраняется внутри каждой ветки.
- Уровни I–IV и V ранг реализуются по-разному: V — покупка звания и три независимые линии улучшений с суммарно девятью ступенями.
- Бонусы от предметов, вспомогательные способности, свитки и гербы необходимо выдавать реально, а не только показывать в подсказке.
- Проводник загробного мира меняет результат по ранее выбранному званию: через фонарь — души из тел, через лук — души из убитых врагов.
- Названия (например, Bishop/Oracle, Light Bishop/Light Oracle) могут различаться между англоязычными локализациями/гайдами; механики сверены по первоисточникам.
- При подключении нового каталога нужна миграция старых сохранений, чтобы не потерять накопленные ОИ или выбор существующего пути.
