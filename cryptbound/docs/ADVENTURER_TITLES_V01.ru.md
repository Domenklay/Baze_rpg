# Дерево авантюриста — рабочая спецификация v0.1

Дата: 2026-11-12. Статус: **ПРОЕКТ механик для последующего согласования** (не утверждённые окончательные числа). Главный принцип выбран пользователем: **пять рангов, путь только по одной ветке**, альтернативные звания не покупаются параллельно.

## Схема рангов (15 узлов / 4 возможные вершины)

\`\`\`text
I    Ученик авантюриста
                |
II        /-----------\
         Искатель   Мародёр
           |           |
III    /-------\   /-------\
       Следопыт Взломщик Духолов Собиратель останков
          |       |       |       |
IV     Тайновед Археолог Проводник душ Анатом
          |       |       |       |
V      Охотник  Хранитель Жнец     Хранитель
       за тайнами реликвий душ    памяти
\`\`\`

На каждом переходе выбирается **ровно один** потомок текущего звания. Игрок может улучшать выбранные ранги (например до 3/3), но не покупать братьев/кузенов. Можно качать отдельные деревья воина и мага за свои ОИ при наличии общего бюджета — путь определяется **внутри каждого дерева**, а не ограничением всей игры одним деревом.

## Предлагаемые узлы и эффекты (до баланса)

| Ранг | Звание | Требует | Эффект за 1/2/3 улучшение или триггер |
|---|---|---|---|
| I | Ученик авантюриста | — | +ОИ за исследование/встречу с редким объектом, небольшая прибавка |
| II | Искатель | I | Увеличивает шанс заметить тайник и предупреждает о некоторых ловушках |
| II | Мародёр | I | Выделяет особые останки, повышает количество лута из опасных источников |
| III | Следопыт | Искатель | После входа в малую комнату шанс открыть намёк на крайний секрет |
| III | Взломщик | Искатель | Дополнительная награда из запертых сундуков/механизмов, не выдаёт обязательный ключ бесплатно |
| III | Духолов | Мародёр | Шанс получить обычную душу при убийстве подходящих существ |
| III | Собиратель останков | Мародёр | Дополнительное извлечение предмета/записки и шанс души из сюжетного трупа |
| IV | Тайновед | Следопыт | Явная подсветка скрытой кромки побочной карты; не снимает стоимость подбора |
| IV | Археолог | Взломщик | Даёт альтернативное решение руин/головоломки и шанс уникального артефакта |
| IV | Проводник душ | Духолов | Усиливает расходуемые души, шанс получить более качественную душу |
| IV | Анатом | Собиратель останков | Возможность распознать особый труп и получить дополнительную связанную находку |
| V | Охотник за тайнами | Тайновед | Открывает некоторые особые секретные комнаты (которые не раскрывает обычная зачистка) |
| V | Хранитель реликвий | Археолог | Дополнительный способ применения найденной реликвии без дублирования одноразовых наград |
| V | Жнец душ | Проводник душ | Редкая сильная душа из подходящих элит/боссов; у боссов ограничение один раз за победу |
| V | Хранитель памяти | Анатом | Уникальные воспоминания/реликвии из особых останков, связанные с общей историей |

Числовая шкала для тестов (НЕ утверждено): II = 10/15/20% шанс вторичной находки, III = 15/25/35%, IV — гарантированная подсветка на отдельных подходящих побочных картах, V — одна особая встреча в подходящем пуле, но **не** на каждом этаже. Избегать зацикленных бесплатных ресурсов.

## Сюжетные останки и связанная добыча

**Пример**: тело погибшего механического исследователя.
- Любой герой: доспех 4★, повреждённый дневник, зацепка для квеста.
- Ветка останков: дополнительно извлекает уникальную душу.
- После использования души: перчатка/механическая рука с вероятностью выпустить электрический разряд при ударе.
- Предмет и душа — **разные награды**, сюжетно связанные. Не выдавать обе всем игрокам автоматически.
- Каждая сюжетная находка имеет стабильный идентификатор и флаг \`claimed\` в экспедиции, чтобы перезаход через Врата Земли не выдавал уникальную находку повторно.

## Технические контракты

- Данные: \`id, tree=adventurer, rank=1..5, parent_id, max_level, cost_ep, trigger, payload, description\`.
- При покупке проверять \`parent.level > 0\` **и всех конфликтующих братьев на каждом предковом уровне**.
- Для старых сохранений с ошибочно купленными конкурирующими званиями: не удалять прогресс молча. Запланировать явную миграцию/компенсацию при включении новой системы в экспедициях.
- Срабатывание поиска тайника: событие генерации/входа в комнату, которое не зависит от того, какая клетка под спрайтом героя. Секрет не открывается обычной автоматической зачисткой.
- Души из обычных существ, сюжетных трупов, элит и боссов имеют разные источники и отдельные ограничения на количество.
- Награды за событие, уже выданные в этом забеге, не должны возобновляться без ограничения при использовании Врат Земли.
- Тесты: невозможность купить братьев и потомков конкурирующих веток; сохранение пути между 1-й и 2-й локацией; сброс после 3-й/смерти; отсутствие двойного получения уникальных душ/сундуков.
