# Пепельный лабиринт — v0.2.0

Самостоятельный полностью офлайн Android roguelike, вдохновлённый раскрытием плит, этажными ключами и разветвлённой системой титулов Gumballs & Dungeons. Арты, персонажи, названия, события и исходники оригинальные; прежняя Baze RPG живёт в отдельном модуле `app`.

## Управление

1. Выберите Некроманта, Палача или Следопыта.
2. Нажмите закрытую каменную плиту — она перевернётся, открывая содержимое. Только открытие плиты не собирает предмет автоматически.
3. Если открылась пустая клетка, она становится тёмным полом без кнопки.
4. Нажмите обнаруженные монеты, сундук, эликсир, тайник или трофей после победы, чтобы забрать награду; затем появится окно полученного лута.
5. Атакуйте обнаруженных врагов нажатием на их клетку или кнопку удара. Враги атакуют на каждом совершённом ходе. Призываемый скелет помогает в бою.
6. У одного из монстров есть ключ от лестницы; на этажах с боссом ключ у босса. После его смерти подберите ключ с плитки и найдите лестницу. Уничтожать всех остальных врагов необязательно.
7. Меняйте вкладки «Герой», «Магия», «Таланты», «Сумка» для прокачки и управления экипировкой.
8. В сумке можно выбирать тип предмета, смотреть параметры надетого и нового с разницей, экипировать, затачивать или разбирать. В герое 9 слотов вокруг изображения персонажа.
9. После смерти остаются осколки памяти: в лагере можно купить постоянные улучшения и начать новый забег.

## Развитие

Три самостоятельные ветки: **Битва**, **Магия**, **Приключение**. В каждой 5 ступеней, 15 титулов с разветвлениями, по три улучшения на титул. Итого **45 титулов / 135 ступеней улучшений**. Эффекты титулов работают в бою, заклинаниях, призывах, разведке, сундуках и торговле.

## Сборка и проверка

Нужны Android SDK 35, JDK 17, Gradle (8.11 в GitHub Actions) и подключение к интернету **только при сборке**, чтобы скачать инструменты сборки. На устройстве приложение не запрашивает разрешения INTERNET.

```bash
node cryptbound/tests/smoke.cjs
gradle :cryptbound:assembleDebug --no-daemon
```

Workflow: `.github/workflows/cryptbound.yml`. Релизная тестовая сборка debug-подписи, поэтому для Google Play она не предназначена.

Данные хранятся локально в WebView storage. Удаление приложения может удалить сохранения.
