## Исследование подземелья

- **5×5, стартовая точка героя по центру** (ромб на полу). Исследование распространяется по ортогональным соседним открытым клеткам, связанным со стартовой точкой.
- Скрытую плиту нельзя открыть без соседней исследованной клетки. **Живой раскрытый ближний враг блокирует исследование соседних плит**, пока не будет побеждён.
- Один тип дальника — **Разбойник-лучник** — иногда появляется раскрытым и стреляет раз в три хода. Он не блокирует соседние клетки и не создаёт удалённого «телепорта» для исследования.
- Открытие клетки = один ход. Подбор предмета = один ход. Обнаружение закрытых клеток по навыкам следопыта и магии также уважает исследованную границу.
- Призываемый некромантом скелет стоит **на отдельной свободной клетке**. Если открытых свободных плит нет, выбирается случайная скрытая пустая и открывается для призыва.
- Враги/существа на клетках показывают HP слева сверху, таймер до особого действия слева снизу, урон справа снизу. Долгое нажатие показывает характеристики и навыки.
- Лут подбирается повторным нажатием на плитку, простые награды показываются всплывающим названием; для сундуков с несколькими наградами остаётся подробный список.
- После победы над держателем ключа ключ необходимо подобрать с клетки, чтобы пользоваться лестницей.

## Игровой контент из RPG Clicker Infinity

Источник — собственный проект [Domenklay/Rpg_clicker_infinity](https://github.com/Domenklay/Rpg_clicker_infinity).

- **Шесть играбельных героев**: воин, воительница, лучник, кинжальщица, некромант, волшебница. Для всех импортированы реальные PNG ожидания, атаки и навыка — 18 ресурсов в \`src/main/assets/imported/\`.
- **Шесть регионов**: Лесная окраина, Каменистое нагорье, Туманные топи, Алые каньоны, Сияющие глубины, Черностекольный разлом. Каждый регион выбирается для четырёх последовательных этажей.
- **156 видов противников** (по 20 обычных, 5 элит и одному боссу для каждого региона). Визуал врагов пока использует временные готические значки: полноценные спрайты врагов в исходном кликере ещё не готовы.
- **12 фиксированных комплектов T1–T2**, каждый с бонусами за 2/4/6 частей, и **24 фиксированных вида оружия**. Основа имён и характеристик — \`GameData/Equipment/ApprovedCatalog.json\`; недостающие аналоги пояса/сапог адаптированы для текущих девяти слотов.
- Материалы и вероятности добычи перенесены из \`Docs/T1T2_156EnemyLootMatrix_Proposal.csv\`. **Важно:** исходный CSV — проектный баланс, не утверждённый релизный. Имена/шансы можно уточнять после тестов.
- Кузница, казармы и библиотека поселения улучшаются навсегда за материалы, подобранные с врагов. Деньги на развитие города не расходуются.

Графика лабиринта пока остаётся оригинальной готической векторной: большие фоновые атласы исходного кликера (размеры каждого по нескольку мегабайт) не импортировались. Полноценный перенос таких фонов можно сделать отдельно после оптимизации.

## Экипировка и прогресс

При нажатии на слот героя открывается модальное окно с надетым предметом слева и выбранным справа. Показываются **только изменяющиеся или ненулевые параметры**, цветная разница и бонусы набора. Девять слотов, заточка +9, 45 универсальных временных титулов, 6 линий постоянного развития героев, реликварий, бестиарий и достижения.

## Сборка и тесты

\`\`\`bash
node cryptbound/tests/smoke.cjs
gradle :cryptbound:assembleDebug --no-daemon
\`\`\`

GitHub Actions: \`.github/workflows/cryptbound.yml\`. Требуются Android SDK 35, JDK 17, Gradle 8.9 при сборке. Приложение **не запрашивает разрешение INTERNET**; сохранение только в WebView localStorage.

Внимание: тестовая debug-подпись сборок может отличаться — установка обновления поверх старого APK иногда требует удаления старой версии, что может стереть локальный прогресс.
