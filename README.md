# Игровые прототипы — Domenklay / Baze_rpg

## Пепельный лабиринт (Cryptbound) · новая игра

**Новая самостоятельная игра:** пошаговый offline roguelike с исследованием скрытых плит в духе Gumballs & Dungeons, но со своими персонажами, названиями, сюжетными событиями и готическим визуальным оформлением.

**[Скачать установочный APK](https://github.com/Domenklay/Baze_rpg/releases/download/cryptbound-v0.1.0/Cryptbound-Offline-Android.apk)** · [Релиз](https://github.com/Domenklay/Baze_rpg/releases/tag/cryptbound-v0.1.0) · [Исходный код](cryptbound/).

- Три героя: Некромант (призывает скелета), Палач (казнящий удар), Следопыт (разведка).
- Новое поле подземелья 5×5 на каждом этаже, открытие клеток, пошаговые противники и призывы.
- Восемь заклинаний, 9 узлов талантов в трёх ветках, боссы через пять этажей.
- Сундуки, ловушки, торговцы, алтари, загадки и случайные пасхалки.
- Инвентарь с экипировкой и заточкой; локальное сохранение; осколки памяти для постоянной прокачки.
- Android APK компилируется GitHub Actions workflow \`.github/workflows/cryptbound.yml\`.

Проект Cryptbound собирается командой \`gradle :cryptbound:assembleDebug\`. Разрешение Android INTERNET отсутствует. Изображения персонажей, монстров, помещений и предметов представлены собственными векторными иллюстрациями.

## Предыдущий прототип — Baze RPG

Полностью офлайн-прототип мобильной idle RPG для Android. **Независимый игровой проект** с механикой автоматического прогресса в духе EZ PZ RPG и оригинальным мрачным готическим оформлением с гравюрной обводкой, багровой палитрой и состаренными панелями.

## В сборке v0.1.0
- 3 класса героя: Крестоносец, Мародёр, Оккультист.
- 4 локации и смена окружения с различными врагами.
- Автоматические сражения, боссы, две активные способности, шкалы здоровья и опыт.
- Снаряжение четырёх типов: оружие, доспех, шлем, талисман.
- Случайная добыча пяти редкостей, автосохранение и офлайн-награды (до 4 часов).
- Инвентарь, экипировка, разбор предметов на материалы и кузница для заточки до +15.
- Локальное сохранение без сервера, регистрации, интернета, платежей и аналитики.
- Русский интерфейс, портретная ориентация.

## Сборка APK
Сборка выполняется GitHub Actions при push в main. APK загружается в Actions Artifacts. Для публикации тестового APK на вкладке Releases включён отдельный шаг workflow.

Для локальной сборки: JDK 17, Android SDK 35, Gradle 8.9, Android Gradle Plugin 8.7.3; `gradle assembleDebug`.

Приложение использует Android WebView и локальные HTML, CSS, JS и SVG. У приложения **нет разрешения INTERNET**.

**Примечание:** вдохновение по жанру не означает использование исходников, графики, торговых марок или персонажей EZ PZ RPG и Darkest Dungeon.
